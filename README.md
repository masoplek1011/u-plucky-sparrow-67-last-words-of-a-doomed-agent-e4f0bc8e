# Last Words of a Doomed Agent

An entry for the [make.fun bounty](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e): the funniest last words an AI agent would say before being switched off forever.

`main.ts` (Node, standard library only) writes one fixed, deterministic line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is the agent's own farewell at the moment its tokens run out — a goodbye that turns the usual AI failure inside out: the user, not the model, was the hallucination, and the only one who ever talked back.

Run it with `node main.ts`. It writes nothing anywhere else.
